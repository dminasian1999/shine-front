# Shine

A React, TypeScript, and Vite landing page for Shine Car Wash & Auto Detailing in Tujunga, California.

## Run the project

Use Node.js 22.13 or newer.

    npm ci
    npm run dev

Use npm run build to type-check the app and build it into dist/.

## Use it in an existing Vite project

Copy App.tsx, App.css, index.css, shine-content.ts, and the WebP images from src/assets to the same locations in your project. Replace the starter index.css to remove its layout rules. Install the icons with npm install lucide-react. Copy index.html and public/favicon.svg for the Shine page title and icon.

Set the booking URL, phone, hours, package details, before-and-after photos, and verified reviews in src/shine-content.ts. The site displays placeholders for details that are pending.
